## 📊 Dataset

The project uses the **Social Media Sentiments Analysis Dataset** from Kaggle.

**Dataset:** [Social Media Sentiments Analysis Dataset](https://www.kaggle.com/datasets/kashishparmar02/social-media-sentiments-analysis-dataset)

The dataset contains social media text along with sentiment, platform, timestamp, user, hashtags, engagement metrics, country, and date-related information. The notebook works with **732 records** and ultimately uses the text and sentiment fields for the NLP pipeline.
